<h3>lazyOS is capable of =></h3>

* dragging windows
* when hovouring on a window , that will pop infornt of other windows
* user can write note on the note app
* user can explore some photos in photo app
* and the windows are also closable
* also added a feature that the windows will not go out of the desktop

---
this is build useing 
* HTML
* CSS 
* JS

---
used files and folders are =>

* index.html -> the start page
* style.css -> contains styles of index.html
* OsMainPage.html -> is the main os page
* OsMainPage.css -> holds the css for the os
* .Resources/ -> contains photos used.
